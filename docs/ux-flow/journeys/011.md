# STORY-011 — Import a layered illustration

Evidence: `011-screens/01-empty-layers.png`, `02-imported.png`; live pass 2026-11-08.

## Friction Scorecard

| Metric | Measured |
|--------|----------|
| Interface actions | 2 (open Arrange, choose files) |
| Ideal | 2 |

## Take-away Pass
- Empty state repeats the same sentence in the canvas ("Import artwork to begin arranging your scene.") and in the layer panel ("No layers yet / Import artwork to begin arranging your scene."). One is enough; the canvas should carry the call to action and the panel can stay silent or show only "No layers yet".
- Three separate import affordances: `+ Import`, `Import artwork` (panel), and the canvas message (not clickable). Remove the panel button or the header button; keep one.
- The layer panel's bottom help text (drag to restack, folders, right-click, depth lives in Parallax) is useful but competes with the empty state; defer it until at least one layer exists.
- The floating select/pan tool group is the only visible viewport control before a tool is chosen, with no label explaining that tools are off. A first-time user can read it as decorative.
- After import, layer rows carry name, thumbnail, visibility, lock, delete and menu in one compact row — dense but each control earns its place.

## The Simpler Version
1. On an empty scene, the canvas shows a single primary **Import artwork** button.
2. Choosing files imports them and selects the newest layer; the canvas button disappears.
3. The layer panel lists rows; its help text appears once a layer exists.

Concrete changes: make the empty-state import a real primary button in the canvas; remove the duplicate panel empty state; remove one of the two header/panel import buttons; hide the layer help text until there is a layer.

## Clarity Issues
- `+ Import` vs `Import artwork` for the same action.
- No stated accepted formats (PNG/JPEG/WebP) until an unsupported file is rejected.
- `0 LAYERS` is plain text rather than a heading, while `SCENES` above uses a heading and count.

Verdict: acceptable
