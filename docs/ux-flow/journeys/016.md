# STORY-016 — Place and resize artwork directly

Evidence: `016-screens/01-selected.png`, `02-moved.png`, `03-inspector.png`; live pass 2026-11-08.

## Friction Scorecard

| Metric | Measured |
|--------|----------|
| Interface actions | 4 (Select tool, select layer, drag, release) for move; +1 per resize/rotate gesture |
| Ideal | 4 |
| Screens | 1 (Arrange) |
| Needless decisions | 1: Select vs Pan as two independent toggles before any interaction; a first-time user must pick a mode |
| Re-entry | Exact X/Y/Scale must be typed if precision is needed; values are already known but not editable in place on the canvas |
| Confirmations | None |
| Dead ends | None; the inspector updates live |
| Hesitations | Selection handles only appear after choosing a tool; with no tool active the canvas looks inert |

## Take-away Pass
- Toolbar contributes Select, Pan, zoom out, 100%, zoom in, grid, snap — seven controls for a core gesture. Zoom controls stay hidden until a tool is on, which is reasonable progressive disclosure but makes the first interaction ambiguous.
- Layer Properties shows the selected name, transform rows, reset/fit, five alignment buttons and Advanced. No single primary action: that is correct for a properties panel, where every control is a tool rather than a step.
- The selected layer name appears twice (row and inspector summary). For a properties panel, repeating the target is justified; keep.
- Advanced holds read-only asset size and on-canvas size. These duplicate what the transform fields and handles already imply; they are reference data, so collapsing them is right.
- Nudge, group move and snapping are invisible affordances: nothing on screen says arrow keys nudge or that snaps target the centre/grid. Acceptable for a pro editor, but not discoverable.
- Inspector numeric fields use left-aligned values with steppers; moving from sliders to exact values is one glance away. Good.

## The Simpler Version
1. Click the artwork directly; selection works without first arming a tool.
2. Drag to move, handles to scale, rotation handle to rotate.
3. Enter exact values in the inspector when needed.

Concrete changes: make Select the default active tool (Pan as a modifier or a hold-Space gesture); add a one-line hint on first selection ("Drag to move · arrows nudge · corner scales").

## Clarity Issues
- Tool state is only an `aria-pressed` toggle; no visible mode label.
- Locked layers silently lose handles; the inspector explains it, but the canvas does not.
- `Reset transform` also resets opacity, which the label does not say.

Verdict: minimal
