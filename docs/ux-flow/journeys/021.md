# STORY-021 — Add a push-in

Evidence: `021-screens/01-catalogue.png`, `02-applied.png`; live pass 2026-11-08.

## Friction Scorecard

| Metric | Measured |
|--------|----------|
| Interface actions | 5 (open workspace, expand category, choose preset, edit duration, submit) |
| Ideal | 3 |
| Screens | 1 workspace + right inspector |
| Needless decisions | 1: Start is always 0 for a first move but is still an editable field; `+ Add another` vs `Update movement` |
| Re-entry | None; chosen preset, timing and target are retained in the form |
| Confirmations | None on the add path; delete and legacy replacement confirm (defensible) |
| Dead ends | Applied list is below the catalogue and can require scrolling; the form remains visible so the next action is clear |
| Hesitations | No preview of the move before adding; description text ("Move toward a point in the scene.") has to carry the decision |

## Take-away Pass
- Catalogue shows three collapsed categories plus six basic cards. The selected card is gold-accented, a clear single selection. Good.
- Applied list repeats the movement name and its timing (`0s + 2s`) with Edit/Duplicate/Delete. That repetition is across surfaces (list vs form) and supports recognition; keep, but timing format differs from Timeline's `start–end`.
- Right inspector repeats the movement name as its heading, then shows Start, Duration, Target X/Y and Travel. All fields earn their place except Start for a first move.
- `Coordinate picker` and its instruction sit at the top of the left pane even when the chosen preset does not use a point. It is a global tool, but visually it reads as part of the preset flow.
- Applied list placement: in Camera Movements it is visible above the fold (02); in Atmosphere it was not (031). Inconsistent placement across sibling workspaces.

## The Simpler Version
1. Choose a movement card.
2. Set duration (default 3s) and, only if needed, target/travel.
3. Click **Add movement**; the applied row appears directly under the selected card with its timing.
4. Edit the applied row in place.

Concrete changes: hide Start until a second move exists (or default to the playhead); pin the applied list above the collapsing catalogue; preview the move on hover; call the same object "movement" everywhere.

## Clarity Issues
- `Update movement` / `+ Add another` / `Cancel edit` is a three-way commit model that only appears when editing.
- Units mix: `Target X · pixels`, `Travel · %`, `Angle · degrees`, `End scale · ×`.
- Target coordinates default to the canvas centre with no visual marker; the picker is the only way to see the point.
- Legacy-track replacement confirmation warns about tracks the user may not recognise; the message explains layer animation is retained, which helps.

Verdict: acceptable
