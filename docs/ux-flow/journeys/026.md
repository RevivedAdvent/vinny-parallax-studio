# STORY-026 — Set depth for foreground and background

Evidence: `026-screens/01-depth-form.png`, `02-depth-applied.png`; live pass 2026-11-08.

## Friction Scorecard

| Metric | Measured |
|--------|----------|
| Interface actions | 4 (open workspace, expand section, choose Depth-based parallax, Apply depth settings) before any per-layer adjustment |
| Ideal | 3 |
| Screens | 1 workspace + right inspector |
| Needless decisions | 1: whether to use the global strength or per-layer influence; both are shown at once |
| Re-entry | None; depth values are pre-filled and editable |
| Confirmations | Apply is a commit, not a confirmation; Reset to neutral has no confirmation in the form and a confirm on the applied row — inconsistent |
| Dead ends | None; form and applied row both remain visible |
| Hesitations | The unit explanation contradicts the control: the form says depth runs 0–1, then shows 50%, 66.7%, 0% |

## Take-away Pass
- The form is long: Parallax strength (range + output), then every layer with Influence % and Depth slider + percentage, then two actions. For three layers that is six controls plus two buttons; each earns its place, but there is no per-layer grouping affordance.
- Layer names truncate (`01-backgr…`), so the user must infer which layer they are changing. The thumbnail exists in Arrange but not here. Add a thumbnail or a tooltip with the full name.
- Two commit controls (`Apply depth settings`, `Reset to neutral`) plus the applied row's `Edit`/`Reset` produce three different routes to the same settings.
- The instruction text explains the concept above the action, which is appropriate for a novel parameter; keep, but correct the units.
- Applied list summary reads `Strength 100% · 02-layer 1 100%, 03-layer 2 100%` — dense and without depth values, so the saved result is not verifiable from the list.

## The Simpler Version
1. Choose Depth-based parallax.
2. Set parallax strength once.
3. Move each layer's depth with a visible thumbnail and numeric value; changes preview live.
4. Changes are saved automatically, with a single **Reset** action.

Concrete changes: unify depth units (percentage only) in copy and labels; show thumbnails and full names; live-apply instead of Apply; one Reset route; include each layer's depth in the applied summary.

## Clarity Issues
- "Depth" is both a percentage and a 0–1 prose scale in the same help text.
- "Influence %" vs "Parallax strength %" are two multipliers with no explanation of how they combine.
- "Reset to neutral" (form) vs "Reset" (applied row) vs "Reset camera movement" (Camera Movements) — three reset idioms.
- Depth is absent from Arrange by design; the Arrange help sentence is the only pointer, so the concept is learned late.

Verdict: acceptable
