# STORY-031 — Add drifting fog

Evidence: `031-screens/01-catalogue.png`, `02-applied.png`; live pass 2026-11-08.

## Friction Scorecard

| Metric | Measured |
|--------|----------|
| Interface actions | 6 (open workspace, expand category, choose fog, start, duration, submit) |
| Ideal | 3 |
| Screens | 1 workspace + right inspector |
| Needless decisions | 1: which of seven "ATMOSPHERE AND DEPTH" cards; resolved by description |
| Re-entry | None; timing is pre-filled from the scene |
| Confirmations | None to add; delete confirms |
| Dead ends | **Measured**: the applied-effects list is below the catalogue and out of view at 900 px; the user cannot see that the effect was created without scrolling |
| Hesitations | The selected card stays highlighted after adding, so the same screen also shows "Update effect" — it is ambiguous whether the effect already exists or is still a preset |

## Take-away Pass
- The left pane stacks two collapsible catalogues (7 + 7 cards) above the applied list. For a creation-first screen, creation is favoured; for returning to tweak, it is buried. An applied list pinned above the catalogue would serve both.
- The right form shows 12+ fog parameters plus timing and loop. Each parameter is legitimate for fog, but they appear at once with no basic/advanced split. Timing and the most visible two or three controls should lead; the rest can be progressive.
- `Add effect` vs `Update effect` + `+ Add another` + `Cancel edit` again creates a three-way commit model. Once editing, the selected catalogue card still reads as a preset selection.
- The form's help text (target scope, region, stylized caveats) sits above the fields; useful for haze/rays but adds reading before the action on every card.
- The catalogue repeats group headings (`ATMOSPHERE AND DEPTH`, `NATURE AND WEATHER`) that also appear in the left nav labels; this grouping is the actual navigation, so keep.

## The Simpler Version
1. Choose an atmosphere card.
2. Set start/duration (pre-filled) and adjust two or three visible parameters; everything else is under **More settings**.
3. Click **Add effect**; the applied list sits directly above the catalogue and the new row is selected.
4. Edit in place; delete from the row with one confirmation.

Concrete changes: pin the applied list above the catalogue (or split the pane: applied above, catalogue below); default-collapse advanced parameters; clear the preset highlight or label the form "Editing Ground fog" after add; keep one commit action.

## Clarity Issues
- "Repeats inside the clip" is a loop checkbox with no explanation of what repeats (the whole effect).
- `Character` (snow vs ash) appears only for one effect; a hidden conditional field.
- Atmosphere effects and camera movements are both called "effects" in lists and "movements" in their workspace, but atmosphere effects are also called "effects" in Timeline — naming is consistent here; the inconsistency lives in Camera Movements.
- A blank scene can still receive fog (observed on scene 2 before artwork), and the preview then says "Import artwork…" next to a live atmosphere row; the product permits an effect with nothing to affect.

Verdict: acceptable
