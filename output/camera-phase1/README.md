# Camera core sample

This tracked directory intentionally contains no rendered frame sequence. The PNG frames, render manifests, browser screenshots, contact sheets, MP4 exports, and other generated evidence are excluded from Git.

Use `npm run render:frames -- --dir output/camera-phase1` to create a local frame-perfect render. Use a new output directory for subsequent renders because exporters protect existing artifacts from overwrite.

The example camera-core JSON is included alongside this README.
